# ห้องทดลองฟิสิกส์ TPAT3

เว็บแบบจำลองฟิสิกส์แบบโต้ตอบ ครบ 15 บทตามเนื้อหา TPAT3 (83 แบบจำลอง) สำหรับสอน ทบทวน และลองโจทย์เอง

- **แอนิเมชัน** เล่น/หยุด/เริ่มใหม่ ปรับความเร็วได้ 0.1×–4× (กด Space เพื่อเล่น/หยุด)
- **ปรับค่าละเอียด** ทุกตัวแปรมีทั้งแถบเลื่อนและช่องพิมพ์ตัวเลข ใส่ค่าตามโจทย์ได้ตรงๆ
- **ลากวัตถุในภาพ** จุดวงกลมประคือสิ่งที่ลากได้ เช่น ย้ายกล่องบนพื้นเอียง ลากยอดพื้นเอียงเปลี่ยนมุม ย้ายน้ำหนักบนคาน เล็งปืน ย้ายเป้า ย้ายประจุ
- **เพิ่ม/ลบชิ้นส่วน** เช่น น้ำหนัก จุดรองรับ เชือก สปริงบนคาน ช่วงความเร่งของรถ จุดควบคุมรางเลื่อน จุดประจุ ตัวต้านทาน เครื่องใช้ไฟฟ้า
- **กราฟสด** วาดพร้อมการเคลื่อนที่ (x-t, v-t, a-t, พลังงาน, P-V ฯลฯ) เปิดปิดแต่ละเส้นได้
- **มุมมอง 3D** ในแบบจำลองที่ช่วยให้เข้าใจ (ป้าย 3D) ลากเพื่อหมุน ล้อเมาส์เพื่อซูม ลากด้วยคลิกขวาหรือ Shift เพื่อเลื่อน
- **ตารางทิศทาง** บอกว่าเพิ่มตัวแปรหนึ่งแล้วผลลัพธ์แต่ละค่า ↑ ↓ หรือไม่เปลี่ยน
- โหมดมืด/สว่าง ใช้บนมือถือได้ ทำงานออฟไลน์ได้ (three.js อยู่ในโฟลเดอร์ `vendor/`)

ไม่ต้องติดตั้งอะไร เปิด `index.html` ในเบราว์เซอร์ได้เลย

## วิธีใช้

- **เปิดในเครื่อง:** ดับเบิลคลิก `index.html` (ฟอนต์จาก Google Fonts ต้องใช้อินเทอร์เน็ต ถ้าออฟไลน์จะใช้ฟอนต์ของระบบแทน ทำงานได้ปกติ)
- **ไฟล์เดียว:** รัน `node tools/build.js` ได้ `dist/tpat3-single.html` ที่รวมทุกอย่างไว้ในไฟล์เดียว ส่งให้นักเรียนหรืออัปโหลดขึ้นเว็บได้ทันที
- **ลิงก์ตรงไปยังแบบจำลอง:** ต่อท้าย URL ด้วย `#<รหัสบท>.<ลำดับแบบจำลอง เริ่มที่ 0>` เช่น `index.html#equil.0` (คานแก้ไขได้) `index.html#general.17` (โจทย์สัมพัทธภาพข้อ 14) หรือ `index.html#home` (สารบัญ)
  รหัสบท: `sci` `kin` `newton` `equil` `energy` `momentum` `proj` `circ` `shm` `elec` `thermo` `solid` `fluid` `general` `env`

## โครงสร้างโปรเจกต์

```
index.html              โครงหน้าเว็บและรายการ <script>
css/style.css           สไตล์ทั้งหมด (สีเป็น token รองรับโหมดมืด)
vendor/three.min.js     three.js r149 สำหรับมุมมอง 3D (MIT License)
js/engine.js            แกนกลาง: เมนูบท แผงควบคุม รายการเพิ่ม/ลบ แอนิเมชัน ลากวัตถุ ตารางทิศทาง
js/draw2d.js            ตัวช่วยวาด 2D บน canvas ด้วยพิกัดเมตร (Lab.G2)
js/graph.js             กราฟสด (Lab.Graph)
js/view3d.js            มุมมอง 3D และตัวช่วยสร้างวัตถุ (Lab.V3)
js/kit.js               ชิ้นส่วนที่ใช้ซ้ำ: รถ ลูกบอล แกนตัวเลข เส้นโค้งราง ตัวสุ่ม (Lab.kit)
js/chapters.js          รายชื่อ 15 บทตามสารบัญ
js/subjects/*.js        แบบจำลองแยกตามบท (fluid.js optics.js relativity.js คือชุดเดิมแบบภาพนิ่ง SVG)
js/subjects/_template.js แม่แบบแบบจำลองใหม่ (ไม่ถูกโหลด)
tools/build.js          รวมเป็นไฟล์เดียว
dist/tpat3-single.html  ผลจาก build
```

## เพิ่มแบบจำลองใหม่

1. คัดลอก `js/subjects/_template.js` เป็นไฟล์ใหม่ เช่น `js/subjects/torque.js`
2. แก้แบบจำลอง แล้วเรียก `Lab.add('<รหัสบท>', CASES)` ที่ท้ายไฟล์ (ถ้าเป็นบทใหม่ เพิ่มบรรทัดใน `js/chapters.js` ก่อน)
3. เพิ่ม `<script src="js/subjects/torque.js"></script>` ใน `index.html` ก่อน `Lab.start()`
4. เปิดหน้าเว็บตรวจดู แล้วรัน `node tools/build.js` และ commit

### ฟิลด์ของแบบจำลอง

| ฟิลด์ | ความหมาย |
|---|---|
| `name` `title` `desc` `formula` | ชื่อแท็บ หัวข้อ คำอธิบาย สูตร (ใส่ HTML ได้) |
| `group` | ชื่อกลุ่มของแท็บในบทเดียวกัน (ไม่บังคับ) |
| `params` | ตัวแปรที่ปรับได้: แถบเลื่อน `{id,label,unit,min,max,step,def}` · ค่ากำหนด `{...,vals:[...]}` · ปุ่มเลือก `{id,label,opts:[[ค่า,ป้าย]],def}` · เปิด/ปิด `{id,label,type:'bool',def}` · หัวข้อย่อย `{type:'head',label}` · รายการเพิ่ม/ลบ `{id,type:'list',label,item,min,max,fields,def,add}` ทุกชนิดใส่ `show:(P)=>bool` เพื่อซ่อน/แสดงตามเงื่อนไขได้ |
| `presets` | ปุ่มลัด `[{label,set:{...}}]` |
| `actions` | ปุ่มบนแถบเครื่องมือ `[{label,run(P,st,O)}]` เช่น สุ่มโจทย์ ล้างรอยทาง |
| `outs` | ค่าที่คำนวณ `[{id,name,unit}]` หรือฟังก์ชัน `(P,O)=>[...]` ถ้าจำนวนเปลี่ยนตามรายการ |
| `compute(P)` | คืน object ผลลัพธ์ (key ขึ้นต้นด้วย `_` คือค่าภายในใช้ส่งต่อให้การวาด) |
| `check(P,O)` | คืน array ข้อความเตือน |
| `extra(P,O)` | ตารางเสริม `{title, html}` |
| `sim` | แอนิเมชัน 2D: `init(P,O)` สถานะเริ่ม · `step(st,dt,P,O)` ขยับทีละ dt ตั้ง `st.done = true` เมื่อจบ · `view(P,O,st)` พื้นที่โลก `{x0,x1,y0,y1,bottom?}` · `draw(g,st,P,O)` วาด · `dt` `tmax` `loop` `autoplay` (ไม่มี `step` = ภาพนิ่งที่ลากได้) |
| `handles(P,O,st)` | จุดที่ลากได้ `[{id,x,y,set:(x,y)=>({param:ค่า})}]` ใช้ `'list.i.field'` สำหรับค่าในรายการ |
| `plot` | กราฟสด `{series:[{label,unit,c,f(st,P,O)}], x?, overlay?}` |
| `live` | ค่าที่แสดงสดใต้ภาพ `[{name,unit,f(st,P,O)}]` |
| `three` | มุมมอง 3D `{cam(P,O), build(T,P,O), update(obj,st,P,O,T)}` ดูตัวช่วยใน `js/view3d.js` |
| `aspect` | สัดส่วนกว้าง:สูงของภาพ (ค่าเริ่มต้น 16/9) |
| `sens: false` | ปิดตารางทิศทาง |
| `draw(P,O)` | (แบบจำลองภาพนิ่งชุดเดิม) คืน SVG 640×300 |

สีที่ใช้ได้ (เปลี่ยนตามโหมดให้เอง): `--ink --muted --line --grid --panel --bg --accent --ray --ray2 --img --water --water-soft --block --block2 --spring --ground --rope --c1 … --c6 --pos --neg --good --bad --warn`

## ข้อตกลงที่ใช้

- g = 9.8 m/s² เว้นแต่ปรับเอง ทิศขวาและขึ้นเป็นบวก
- ภาพบางแบบจำลองขยายแนวดิ่งหรือเร่ง/ชะลอเวลาเพื่อให้เห็นชัด ตัวเลขในช่องผลลัพธ์คือค่าจริง
- ค่าวัสดุ ค่าไฟ และค่าการปล่อยคาร์บอนเป็นค่าประมาณเพื่อการเรียนรู้ ปรับให้ตรงข้อมูลปัจจุบันได้

## เริ่มใช้ git

โฟลเดอร์นี้สร้างโดยเครื่องมือที่เขียนลงโฟลเดอร์ `.git` ไม่ได้ เปิดเทอร์มินัลในโฟลเดอร์นี้แล้วรัน:

```bash
git init -b main
git add -A
git commit -m "เริ่มต้นโปรเจกต์ ห้องทดลองฟิสิกส์ TPAT3"
```

ถ้ามี repo อยู่แล้ว ใช้ `git add -A` แล้ว `git commit` ตามปกติ
แนะนำ commit แยกหนึ่งบทหรือหนึ่งแบบจำลองต่อครั้ง และรัน `node tools/build.js` ก่อน commit เพื่อให้ `dist/tpat3-single.html` เป็นเวอร์ชันล่าสุด
